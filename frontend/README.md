# ConnectIQ – Smarter Ways to Connect

An AI-powered social media and real-time chat application (frontend).

## Tech Stack
- React 19 + Vite
- Tailwind CSS 4 + daisyUI 5
- React Router

## Features (UI)
- Login & Signup
- Home feed with likes and comments
- Create Post with **AI Caption Generator**
- Explore & search people
- Profile page with edit profile
- Real-time chat with **Smart Reply** and **AI Conversation Summarizer**
- Fully responsive (mobile, tablet, desktop)

## Getting Started
```bash
npm install
npm run dev
```
Open http://localhost:5173

> The UI currently uses dummy data from `src/data/dummyData.js`.

## Folder Structure
```
src/
├── components/   # Reusable parts (Layout, PostCard, Avatar, Logo...)
├── pages/        # Home, Explore, Profile, Chat, Login, Signup
├── data/         # Dummy data
└── styles/       # CSS with meaningful class names (one file per page)
```
